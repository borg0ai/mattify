Call the Skill tool with "grilling".
After the user confirms shared understanding, if the subject is a software product, architecture, or behavior change, invoke the host-installed `/specify` skill in the same conversation to create an RFC. Do not create an issue spec or ADR as a substitute. For unrelated subjects, finish with the shared understanding and do not force an RFC.
