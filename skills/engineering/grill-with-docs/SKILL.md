---

Call the Skill tool twice, for "grilling" and "domain-modeling". After the user confirms shared understanding, when the discussion concerns a software product, architecture, or behavior change, invoke the host-installed `/specify` skill in this conversation and use its RFC as the durable proposal. Do not write an issue spec or use an ADR as a substitute. For unrelated discussions, finish with the shared understanding and do not force an RFC.
